# Приложение `app_core` (Ядро проекта)

**`app_core`** — это центральное приложение проекта «Ломбард Народный».  
Оно отвечает за базовый каркас сайта, главную страницу и связывает все остальные модули воедино.

## 🎯 Назначение приложения

1. **Базовый шаблон (Layout)**: Хранит `base.html`, который содержит «скелет» всех страниц  
(шапка с логотипом и навигацией, подвал). Все остальные HTML-шаблоны наследуются от него.
2. **Главная страница**: Рендеринг корневой страницы сайта (`/`),  
на которой расположены основные блоки навигации (квадранты).
3. **Общие модели (опционально)**: Если в проекте есть модели, которые используются везде  
(например, настройки сайта, мета-теги по умолчанию), они лежат здесь.
4. **Связующее звено**: Обрабатывает базовые маршруты, которые не относятся 
к конкретным бизнес-сущностям (например, главная страница).

## 📂 Структура и ключевые файлы

- `templates/base/base.html` — главный шаблон сайта. Содержит фиксированную шапку (sticky),  
подвал, подключение статики и глобальные CSS-стили.
- `templates/index.html` — шаблон главной страницы (наследуется от `base/base.html`).  
Содержит адаптивную сетку (quadrant-grid) со ссылками на разделы:  
Филиалы, Цены, Условия, Вопросы и ответы.
- `views/base.py` — основные представления:
  - `index` — рендер главной страницы.
- `views/` — папка для разделения логики представлений по файлам.
- `urls.py` — корневые маршруты проекта (главная страница и базовые системные страницы).

## 🛠 Как это работает

1. **Шаблон `base.html`**:
   - В шапке реализована фиксированная навигация (`position: fixed` или `sticky`), 
   которая не уезжает при скролле.
   - Логотип ведёт на главную страницу.
   - Кнопки навигации: «Меню», «Город» (заглушки), «Филиалы» (`{% url 'branches' %}`), «Личный кабинет».
   - В подвале ссылки на «О нас» и «Контакты».
   - Подключены глобальные стили для типографики и сброса отступов.

2. **Главная страница (`index.html`)**:
   - Использует CSS Grid для создания 4 квадрантов, которые ведут на соответствующие разделы.
   - Картинки для квадрантов берутся из папки `static/` (например, `branches.jpg`).

## 🔗 Зависимости от других приложений

- **`app_common`**: Из `base.html` идут ссылки на статические страницы (о нас, контакты).
- **`app_branches`**: Главная страница содержит ссылку на карту филиалов.
- **`app_prices`, `app_common` (условия/вопросы)**: Квадранты главной страницы ведут в эти разделы.

## ⚙️ Особенности реализации

- **Глобальная шапка**: Шапка вынесена в `base.html`, чтобы не дублировать её в каждом шаблоне. 
Если меняется меню, правится только один файл.
- **Статика**: Логотип и картинки главной страницы подключаются через `{% static %}`. 
- **Подключение URL**: В `urls.py` проекта (обычно `project_lombard/urls.py`) 
приложение `app_core` подключено с пустым префиксом `path('', include('app_core.urls'))` 
— поэтому главная страница доступна по корневому URL `/`.

## 🚀 Как добавить новую страницу в ядро

1. Создайте представление в `app_core/views/base.py`.
2. Создайте шаблон, который наследуется от `base/base.html`.
3. Добавьте маршрут в `app_core/urls.py`.
4. Если страница должна быть в меню — отредактируйте `base.html`.

---

**Примечание**: Данное приложение не хранит бизнес-логику, связанную с филиалами,  
ценами или пользователями. Оно предназначено исключительно для объединения интерфейса и системных страниц.
