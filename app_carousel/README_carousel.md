# app_carousel — Карусель изображений на главной странице

Отдельное Django-приложение, отвечающее за баннер-карусель (слайдер изображений)
на главной странице сайта «Ломбард Народный».

Приложение полностью изолировано: загрузка, сортировка и удаление слайдов
происходят через стандартную админку Django, а вывод на сайт — через
кастомный template tag. Никакой другой код проекта (калькулятор, филиалы,
карта) от него не зависит.

## Назначение

Приложение решает одну задачу — **показывать на главной странице карусель
из изображений, которыми управляет контент-менеджер через админку**.

Ключевые требования, которые покрывает приложение:

- Загрузка/удаление изображений через админку Django.
- Сортировка слайдов (поле `order`).
- Возможность временно скрыть слайд без удаления (`is_active`).
- Необязательная подпись поверх изображения (`title`).
- **Если изображений 0** — блок карусели на сайте не рендерится вообще.
- **Если изображение 1** — показывается одно изображение без стрелок,
  точек и автопрокрутки.
- **Если изображений 2 и больше** — полноценная карусель со стрелками,
  точками, автопрокруткой, свайпами и управлением с клавиатуры.

## Как это работает

```
┌─────────────────────┐
│  Админка Django     │  контент-менеджер загружает картинки,
│  (CarouselImage)    │  задаёт порядок и активность
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│  База данных        │  таблица app_carousel_carouselimage
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│  Template tag       │  {% get_carousel_images as carousel_images %}
│  carousel_tags.py   │  возвращает список активных слайдов
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│  Шаблон index.html  │  разметка + CSS + JS карусели
└─────────────────────┘
```

1. **Контент-менеджер** заходит в `/admin/` → раздел **«Карусель»**.
2. Загружает изображение, задаёт порядок и (опционально) подпись.
3. На главной странице template tag `get_carousel_images` достаёт
   активные слайды из БД и передаёт их в шаблон.
4. Шаблон рендерит секцию карусели (или не рендерит, если слайдов нет).
5. JS-скрипт на клиенте «оживляет» карусель: автопрокрутка, стрелки,
   точки, свайпы, клавиатура.

## Модель данных

### `CarouselImage`

Таблица `app_carousel_carouselimage`.

| Поле         | Тип                          | Назначение                                                       |
|--------------|------------------------------|------------------------------------------------------------------|
| `id`         | `BigAutoField` (PK)          | Первичный ключ                                                   |
| `image`      | `ImageField`                 | Файл изображения (сохраняется в `media/carousel/`)              |
| `title`      | `CharField(200, blank=True)` | Подпись поверх изображения (необязательно)                       |
| `order`      | `PositiveIntegerField`       | Порядок показа. Чем меньше — тем раньше слайд                    |
| `is_active`  | `BooleanField`               | Активность. `False` — слайд не показывается на сайте             |
| `created_at` | `DateTimeField`              | Дата создания (auto_now_add)                                     |

**Сортировка по умолчанию:** `['order', 'id']` — сначала по `order`,
при равенстве — по `id`.

**Загрузка файлов:** функция `carousel_image_upload_to` складывает файлы
в `media/carousel/<имя_файла>`. Django автоматически переименовывает
дубликаты (добавляет суффикс).

## Админка

Настройка находится в `admin.py` → `CarouselImageAdmin`.

**Что умеет:**

- Показывает **превью** каждого изображения прямо в списке (`preview`).
- Показывает **большое превью** на странице редактирования.
- Позволяет **менять `order` и `is_active` прямо из списка**
  (через `list_editable`) — без захода в карточку.
- Фильтр по активности, поиск по подписи.
- Кнопка **«Добавить изображение карусели»** стандартная.

**Список полей в админке:**

```
[Превью] [Подпись] [Порядок] [Активно] [Создано]
```

**Порядок слайдов на сайте** определяется полем `order`, а не порядком
создания. Если у двух слайдов одинаковый `order` — вперёд идёт тот,
у кого меньше `id`.

## Template tag

Файл `templatetags/carousel_tags.py`.

```python
from django import template
from app_carousel.models import CarouselImage

register = template.Library()

@register.simple_tag
def get_carousel_images():
    """Возвращает список активных изображений карусели в заданном порядке."""
    return list(
        CarouselImage.objects
        .filter(is_active=True)
        .order_by('order', 'id')
    )
```

**Использование в шаблоне:**

```django
{% load carousel_tags %}
{% get_carousel_images as carousel_images %}
```

`carousel_images` — это Python-список объектов `CarouselImage`.
Его можно перебирать через `{% for %}` и проверять на пустоту
через `{% if carousel_images %}`.

**Важно:** тег делает один запрос к БД за активными слайдами,
отсортированными по `order`. Никакой кешировки нет — при каждом
рендере страницы данные читаются заново.

## Логика отображения на сайте

Шаблон `index.html` (или тот, где подключена карусель) содержит:

```django
{% get_carousel_images as carousel_images %}

{% if carousel_images %}
<section class="carousel-section" id="carousel">
    <div class="carousel"
         data-count="{{ carousel_images|length }}"
         data-autoplay="true"
         data-interval="5000">
        ...
    </div>
</section>
{% endif %}
```

Поведение в зависимости от количества слайдов:

| Количество активных слайдов | Что видит пользователь                                      |
|-----------------------------|-------------------------------------------------------------|
| **0**                       | Блока карусели нет вообще (секция не рендерится)            |
| **1**                       | Одно изображение. Стрелки, точки, автопрокрутка — отсутствуют |
| **2 и больше**              | Полная карусель: стрелки, точки, автопрокрутка (5 сек), свайпы, клавиатура |

Внутри `.carousel` атрибут `data-count` равен количеству слайдов —
JS использует его, чтобы решить, включать ли интерактив.

## Подключение к проекту

### 1. Добавить в `INSTALLED_APPS`

`project_lombard/settings.py`:

```python
INSTALLED_APPS = [
    # ...
    'app_carousel',
]
```

### 2. Применить миграции

```bash
python manage.py makemigrations app_carousel
python manage.py migrate
```

### 3. Убедиться, что медиа настроено

`settings.py`:

```python
MEDIA_URL = '/media/'
MEDIA_ROOT = BASE_DIR / 'media'
```

`project_lombard/urls.py`:

```python
from django.conf import settings
from django.conf.urls.static import static

if settings.DEBUG:
    urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

> `static()` работает **только при `DEBUG=True`**. В продакшене файлы
> из `/media/` должны раздаваться через nginx/Apache.

### 4. Перезапустить сервер

После добавления приложения в `INSTALLED_APPS` и создания
`templatetags/` **обязательно** перезапустить `runserver` —
Django не подхватывает новые template tags «на лету».

## Использование в шаблоне

Минимальный пример (без CSS/JS) — чтобы просто проверить, что тег работает:

```django
{% load carousel_tags %}
{% get_carousel_images as carousel_images %}

{% if carousel_images %}
    <div class="carousel">
        {% for slide in carousel_images %}
            <img src="{{ slide.image.url }}" alt="{{ slide.title|default:'Слайд' }}">
        {% endfor %}
    </div>
{% endif %}
```

Полная версия с CSS и JS — в `index.html`, в секции
`<section class="carousel-section">`.

## CSS и JS карусели

CSS и JS живут **в шаблоне `index.html`**, а не в приложении
`app_carousel` — это осознанное решение, чтобы не плодить статические
файлы и не подключать лишние теги `{% static %}`.

### CSS

Ключевые классы:

| Класс                    | Назначение                                         |
|--------------------------|----------------------------------------------------|
| `.carousel-section`      | Внешняя обёртка секции карусели                    |
| `.carousel`              | Сам контейнер карусели (aspect-ratio, скругление)  |
| `.carousel__track`       | Дорожка со слайдами (позиционирование)             |
| `.carousel__slide`       | Один слайд (по умолчанию `opacity: 0`)             |
| `.carousel__slide.is-active` | Активный слайд (`opacity: 1`)                  |
| `.carousel__image`       | Изображение внутри слайда (`object-fit: cover`)    |
| `.carousel__caption`     | Подпись поверх изображения (градиент снизу)        |
| `.carousel__arrow`       | Стрелка «назад» / «вперёд»                         |
| `.carousel__dots`        | Контейнер точек                                    |
| `.carousel__dot`         | Одна точка (`.is-active` — текущая)                |

**Адаптив:**

- `≤900px` — aspect-ratio `16/9`, стрелки меньше.
- `≤500px` — aspect-ratio `4/3`, скругление меньше, подпись мельче.

### JS

Логика в `<script>` в конце `{% block content %}`:

- Берёт `data-count`. Если `≤ 1` — выходит сразу (нет интерактива).
- Показывает слайд по индексу через `.is-active`.
- Автопрокрутка каждые `data-interval` мс (по умолчанию 5000).
- Пауза при наведении мыши (`mouseenter` / `mouseleave`).
- Стрелки, точки, свайпы (`touchstart` / `touchend`), клавиатура
  (`ArrowLeft` / `ArrowRight`).
- Восстанавливает автопрокрутку после ручного переключения.

## Настройки и параметры

### Атрибуты `data-*` на `.carousel`

| Атрибут         | Значение по умолчанию | Описание                              |
|-----------------|-----------------------|---------------------------------------|
| `data-count`    | `{{ carousel_images|length }}` | Количество слайдов (задаётся шаблоном) |
| `data-autoplay` | `"true"`              | Включена ли автопрокрутка             |
| `data-interval` | `"5000"`              | Интервал автопрокрутки в миллисекундах |

Чтобы отключить автопрокрутку на конкретной странице — поставьте
`data-autoplay="false"`.

### Поля модели в админке

- `order` — целое число, чем меньше, тем раньше.
- `is_active` — галочка. Снята → слайд не показывается.

## Требования к изображениям

- **Рекомендуемый размер:** 1600×600 px и больше (соотношение ~16:6).
- **Формат:** `.jpg`, `.png`, `.webp` (всё, что поддерживает Pillow).
- **Вес:** желательно до 300–500 КБ — крупные файлы замедляют загрузку.
- **Что видно на телефоне:** из-за `object-fit: cover` по краям
  обрезается — важные детали держите ближе к центру.
- Первое изображение грузится с `loading="eager"` (быстро), остальные —
  с `loading="lazy"` (по мере необходимости).

## Частые проблемы

### На сайте нет карусели, хотя картинки в админке есть

Проверьте по порядку:

1. `'app_carousel'` добавлен в `INSTALLED_APPS`?
2. В шаблоне есть `{% load carousel_tags %}` в самом верху?
3. У картинок стоит галочка **«Активно»**?
4. Сервер перезапущен после добавления приложения?
5. Картинки открываются по прямому URL `/media/carousel/...`?
   Если 404 — не настроен `MEDIA_URL` / `MEDIA_ROOT` или `DEBUG=False`.

### Ошибка `Invalid block tag: 'get_carousel_images'`

- Нет `app_carousel/templatetags/__init__.py` (пустой файл-маркер).
- Приложение не в `INSTALLED_APPS`.
- Сервер не перезапущен.

### Секция в HTML есть, а картинок не видно

- Откройте DevTools (F12) → выделите `.carousel` → посмотрите `height`.
  Если `0` — `aspect-ratio` перебит другими стилями.
- Проверьте, что у первого слайда есть класс `is-active`.
- Проверьте вкладку Console — нет ли JS-ошибок.

### Слайды идут не в том порядке

Порядок определяется полем `order` (по возрастанию), при равенстве — `id`.
Поменяйте `order` в админке (можно прямо в списке через `list_editable`).

## Что можно добавить в будущем

- **Ссылка на слайд** — поле `link` (URL), при клике переход.
- **Разные карусели для разных городов** — связь с `app_branches`,
  фильтр по городу в теге.
- **Планирование показа** — поля `starts_at` / `ends_at`,
  фильтр по дате в теге.
- **Кеширование** — обернуть `get_carousel_images` в `cache.get/set`,
  сбрасывать кеш через `post_save` / `post_delete` сигналы.
- **Вынос CSS/JS в статику** — `static/css/carousel.css` и
  `static/js/carousel.js`, подключение через `{% static %}`.
- **Загрузка нескольких файлов сразу** — кастомная форма или
  сторонняя библиотека вроде `django-multiupload`.
- **Альтернативные карусели** — например, для раздела «Акции»
  на странице новостей, с отдельной моделью или полем `slot`.
