# Приложение `app_prices` (Цены и калькулятор)

Приложение отвечает за хранение актуальных цен на драгоценные металлы (золото и серебро)  
и предоставляет логику для их пересчёта. 

Включает в себя две основные части:
1. **Админскую** — для ручного обновления базовых цен сотрудниками.
2. **Публичную (API)** — для отдачи цен на сайт (используется интерактивным калькулятором  
на главной странице).

---

## 📌 Структура и особенности

### 1. Модель данных (`models.py`)
Используется модель `MetalPrice`.
- Хранит цены **за 1 грамм**.
- Имеет привязку к типу металла (`gold` / `silver`) и пробе (`375`, `500`, `585`, `750`, `850`    
для золота; `875`, `925` для серебра).
- Цены хранятся с копейками (`DecimalField`). Округление до целых рублей происходит   
только на этапе вывода на сайте (в API).

### 2. Логика расчёта (`admin.py`)
В админке реализован кастомный интерфейс. Сотрудник вводит **только базовые цены**:
- Золото 585 пробы.
- Серебро 925 пробы.

Остальные пробы рассчитываются автоматически по пропорции:
- Для золота: `цена_585 * (проба / 585)`.
- Для серебра: `цена_925 * (проба / 925)`.

Для этого в `admin.py` написаны две изолированные функции:
- `price_admin_calculator(main_proba)` — для золота.
- `silver_price_admin_calculator(base_925_price)` — для серебра.

*Важно:* Функции админки и API разделены. Если в будущем понадобится изменить  
логику расчёта для пользователей (например, добавить маржу ломбарда), это не затронет работу админки.

### 3. Пользовательский API (`views/user_calculators.py`)
Отдаёт данные для публичного калькулятора на главной странице.
- **`metal_prices_api`** (URL: `/api/metal-prices/`) — возвращает JSON с актуальными ценами.
- В API применяется округление **до целых рублей** (функция `_round_rub`), 
чтобы пользователь видел красивые цифры без копеек.
- Пробы, которых нет в БД, не попадают в JSON (фронтенд их просто не отрисует).

## 🛠 Как обновить цены

1. Зайдите в админку: `/admin/app_prices/metalprice/`.
2. Нажмите кнопку **«📝 Обновить цены»**.
3. Введите новые цены для **золота 585** и **серебра 925**.
4. Нажмите **«🔢 Рассчитать»** — система покажет, какие цены получатся для всех остальных проб.
5. Если всё устраивает, нажмите **«💾 Сохранить новые цены»**.

После сохранения данные в БД обновятся (старые записи перезапишутся через `update_or_create`),   
и публичный калькулятор на сайте мгновенно начнёт использовать новые цены 
(при следующей загрузке страницы).

Фронтенд калькулятора находится в `app_core/templates/base/index.html` (секция `#metalCalculator`).
1. При загрузке страницы JS делает `fetch` запрос на `/api/metal-prices/`.
2. Получает JSON вида:
   ```json
   {
     "gold": {"375": 5000, "500": 6500, "585": 7500, "750": 9000, "850": 10000},
     "silver": {"875": 95, "925": 100}
   }
